\chapter{MQTT Topic and Command Contract}
\label{app:mqtt}
All listed telemetry/state topics are published retained by the simulator; documented commands are sent non-retained by clients. Payloads are JSON except plain-text status. Values are rounded for transport. MQTT itself does not authenticate these messages in the current broker.

\section*{Known contract defects}
Command validation should add explicit finite-number checks and require an exact allowed time-scale rather than truncating numeric input. Separately, the dashboard publishes the scenario command topic
\begin{center}\path{twin/ecosystem/cmd/scenario}\end{center}
and expects \path{twin/ecosystem/command/result} plus \path{twin/ecosystem/scenario/state}. The simulator subscribes only to room and AHU command wildcards and neither routes nor emits those ecosystem topics. Guided scenario buttons therefore do not work in the audited build.
