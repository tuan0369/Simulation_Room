\section*{Acknowledgement, replay, and audit behavior}
The strict decoder rejects oversized, invalid UTF-8/JSON, non-object and non-finite payloads, invalid identifiers, and unsupported values. The publisher rejects retained commands before queueing. A non-retained command is applied on the simulation thread and emits an application result distinct from MQTT transport PUBACK. Up to 1,024 command IDs are cached in memory: the identical topic/payload is replayed without mutation, while reuse with a different request fingerprint is rejected as \code{command\_id\_conflict}. This is bounded process-local idempotency, not durable nonce/expiry protection.

When \code{ECOHVAC\_AUDIT\_PATH} is configured, the publisher appends sanitized request metadata (topic, ID/source, retain flag, payload hash and byte count) plus the command result to the local SQLite SHA-256 chain. Audit startup/write failures are visible, including in the command result for write failure. The default stack does not enable this path; the chain is not externally anchored or signed and does not authenticate the self-declared source.
