\section{Evidence protocol}
The figures were captured from the then-current Project~2 source during a local run on 14 August 2026. They are state evidence, not a substitute for a machine-readable experiment log. The stress capture was created using validated individual room/AHU MQTT commands. The current implementation now supports correlated \code{twin/ecosystem/cmd/scenario} baseline/stress commands and retained scenario/application-result topics; this historical image is not retroactively evidence that the newer guided button caused the captured state.

For a repeatable submission experiment, occupancy randomness should be seeded or disabled, $\Delta t$, initial state, command sequence, duration, artifact/model hashes, and raw MQTT decisions should be recorded. The expected invariants are $0\le g_i\le r_i$, $\sum g_i\le F^{avail}$, and deterministic priorities from the same snapshot.

\section{Automated verification}
The final project run reports 145 tests passing, covering AHU thermal/electrical semantics, comfort-debt coordination, PID actuator feedback, ecosystem stop/scenarios, strict command validation, retained-command rejection, command-ID replay/conflict handling, optional integrated audit writes/failure visibility, model artifact/OOD/unavailable behavior, exact default-dataset/model/metric reproduction, MQTT payloads, dashboard telemetry/correlation, and presentation helpers. Raw console and JUnit evidence are archived under \code{release-evidence/project2/}; source state is disclosed as a pre-final-commit working tree and must be refreshed after commit.

A real local classroom-broker run additionally archived correlated accepted stress, pause, and baseline results; constrained grants; paused zero instantaneous values with unchanged cumulative energy; and fresh-subscriber retained recovery. Remaining gaps include browser-level automation, broker-loss recovery, field calibration and multivariate drift tests, deployed authentication/TLS/ACL tests, externally anchored comprehensive audit, and proof that risk changes an autonomous action. The latter absence is expected because model action is intentionally advisory.
